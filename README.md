# Binary Search Smart Record Searching System

The program manages a sorted list of IDs or values and supports both iterative and recursive binary search. It visibly shows how the search interval is reduced by half. 

Objective 
Implement both binary-search forms; reinforce the sorted- input condition; compare binary search with a simple sequential scan.

Expected Input 
Sorted values/records; search key; iterative or recursive option; optional repeated searches.

Expected Output
 Found/not found status; record and index; low, high, and mid values at each step; comparison counts for binary and linear search.

Methodology to be used

1. Accept records and either validate sorted order or sort them using a syllabus algorithm. 
2. Implement iterative and recursive binary search separately. 
3. Log low, high, and mid at each iteration/ call. 
4. Handle duplicates by clearly stating which occurrence is returned. 
5. Compare with linear search on the same key. 
6. Test first, middle, last, absent, and single-item cases.
